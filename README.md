# 00406A Tracker — R48 自動閱讀・零匯出按鈕版

以手機操作為主的 00406A 投資追蹤儀表板，保留原有 19 個分頁、5 大分類、主帳戶／大寶／二寶獨立帳務。

## R48 改版摘要

- **移除全部重複工具列**：月報、年報、退休試算、績效、XIRR、家庭現金流、資產比較、配息中心、流動性雷達與篩選結果頁面的「下載 CSV」「獨立 HTML」「列印／PDF」「重新彙整／重新計算」等共 39 個操作按鈕全數移除。
- **維持自動更新／計算**：股價與配息由原有 GitHub Actions 公開資料檔自動更新；各頁計算依切頁、篩選變更與交易／股息紀錄更新觸發，不必額外按「重新彙整」。
- **保留必要互動**：快速記帳、編輯／刪除交易、實際股息登錄、月份／年度切換、篩選和 APP 版本更新提示均保留。
- **不開放下載及列印**：操作介面不再提供 CSV、HTML 或 PDF 匯出入口；原有只讀報表及計算保留。舊匯出程式保留在源碼中以降低回歸風險，但網站沒有對應按鈕。
- **仍無帳務備份／還原**，主帳戶、大寶、二寶繼續分開記錄在本機瀏覽器；沒有私人帳務雲端同步。
- **R47 原版可回復**：`backup/r47-before-r48` GitHub 備份分支（只存程式碼，不含手機帳務）。
- **驗收**：`tests/r45-smoke.cjs` 到 `tests/r48-smoke.cjs` 及 `.github/workflows/test-r45.yml`。

## R47 改版摘要

- **移除所有帳務備份／還原功能**：主帳戶頁的下載／匯入、R30 下載 JSON／校驗／覆蓋流程、每 30 天備份待辦與 R45 首頁備份警示，程式入口均已刪除。
- **改成只讀帳務健康檢查**：仍可檢查交易筆數、重複識別碼、超賣、未來交易、主帳戶與雙寶實收股息格式。檢查**不會刪除、修改或新增**任何交易。
- **三帳戶獨立**：主帳戶不加入大寶或二寶的股數、現金流和績效；各自的逐筆交易及已領股息保留在同一瀏覽器原有的 localStorage。
- **導覽仍維持五大分類**：原「安全與風險」改名「風險與健檢」，包含「帳務健康檢查」和「流動性雷達」，沒有新增冗長的分頁。
- **保留 R45/R46 手機功能**：今日三件事、公開數據可信度、年齡基準 2026＝42 歲、2039/09 停扣／2044/09 退休試算、PWA 離線快取與選用系統通知。沒有新增背景推播伺服器。
- **R48 變更**：月報、年報、XIRR 與量能雷達的 CSV／HTML／PDF 匯出及重複手動刷新按鈕已從介面移除，資料仍可在各自頁面直接閱讀。

## 帳務資料特別注意

本專案**沒有跨裝置自動同步私人帳務的服務，也不再提供本機帳務復原介面**。將 `index.html` 更新到新版本不會主動清除交易或實收股息；但若清除 Chrome 網站資料、重設瀏覽器或遺失手機，本機紀錄可能無法恢復。公開 GitHub 只同步程式與行情資料，不包含主帳戶或雙寶交易。

## R49 盤中最近成交價連動（保留 R48 所有功能）

- 新增 `.github/workflows/update-quote.yml`，台灣交易日約每 5 分鐘嘗試取得 TWSE MIS 最近成交價，寫入 `data/quote.json`；GitHub 排程可能延遲或跳過，因此不是逐筆零延遲行情。
- 網頁開啟時 `js/r49-live-quote.js` 每 60 秒檢查報價檔。只採用當日且距最後成交不超過 20 分鐘、代號和資料結構正確的價格，顯示成交時間；逾期改用最近可用收盤價。
- 更新共用 `currentPrice` 後連動主帳戶市值／損益、雙寶市值、家庭合計、定投購買力、智慧加碼與開啟中的報表／績效試算；不將盤中價寫成日收盤紀錄，也不修改私人帳務。
- 原有每日市場資料與配息排程保留，不能覆寫較新的盤中報價。PWA 沿用原本的「更新 APP」提示。
- 自動測試：`node tests/r49-smoke.cjs`，CI 同時編譯檢查 `scripts/update_quote.py`。

## 市場自動更新

- `.github/workflows/update-market.yml` 定時核對公開市場行情及配息資料。
- `scripts/update_market.py` 讀取證交所資訊，可選擇透過 GitHub Actions Secret `FINMIND_TOKEN` 補長期歷史資料。
- `data/market.json` 為無個人資料的公開市場快照。
- `js/auto-market.js` 開啟網站時讀取快照，更新配息、成交量、行情以及風險分析。
- `js/r45-smart.js` 產生簡潔的規則式摘要，區分已公告預估／正式配息、行情過期與資料來源異常。
- `sw.js`、`manifest.webmanifest`、`js/r46-mobile.js` 提供離線資源與選用的前景提醒。

## 驗收

執行 `node tests/r45-smoke.cjs`、`node tests/r46-smoke.cjs`、`node tests/r47-smoke.cjs`。CI 工作流程為 `.github/workflows/test-r45.yml`。

本專案不自動下單；除息公告及預估金額不會自動登錄為已實收股息。
